# W4.4 — 多模态 / 图片描述检索（F-14）— 暂缓说明

> 对照 plan-review G-06：原 overview 声称「见各文档」但无覆盖。本文件明示 **暂缓** 与准入条件，消除映射失真。

## 现状

- embedding 模型为 doubao multimodal vision，但摄入默认只喂文本
- `doclingEnablePictureDescription=false`，图片不入向量

以上是当前仓库/config 快照，不是供应商能力和成本的永久事实；准入时须保存目标模型版本、地域、输入限制、单价口径和官方文档核对日期。

## 暂缓理由

1. Wave1–2 精度与评估未稳前，上多模态会混入新变量
2. 图片描述增加 docling 成本与延迟，需独立 ROI 评估
3. 无 picture 相关 golden cases
4. 图片可能包含个人信息、扫描签章和敏感图表，尚无脱敏、访问控制和留存方案

- 评估命中率、OCR/描述错误、延迟、存储和模型费用
