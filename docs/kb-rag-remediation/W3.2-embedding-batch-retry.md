# W3.2 — Embedding 批处理与重试（F-07）

> 2026-08-10 实现复核：原文对现状的描述错误。provider 在本轮前已经具备分组、batch、有限并发、按 index 映射和 429/5xx 重试；本轮补的是安全默认值、环境配置、Retry-After/abort/永久 4xx 语义与回归证据。

## 1. 背景与问题

[`DoubaoMultimodalEmbedProvider.embed`](../../packages/llm/core/src/provider/doubao-multimodal-embed.ts) 已按 purpose/profile 规划 batch、通过并发池发送、按响应 `index` 回填原输入位置，并对 429/5xx 重试。`query` 的不同 retrieval profile 不混批；`document` 指令相同，可共用分组。

真正缺口不是“代码完全串行”，而是部署目标模型的批量输入上限没有可靠证据。如果把未经核实的 16 当默认值，可能在目标地域/模型上造成批量失败。因此当前默认 `DOUBAO_EMBED_BATCH_SIZE=1`，只启用有限并发；显式配置大于 1 才启用 vendor batch。

报告 F-07 Major。

## 2. 前提核实、目标 / 非目标

“内部接口接收 `input[]`”不能推出部署中的 vendor endpoint 支持多输入 batch。启用 `DOUBAO_EMBED_BATCH_SIZE>1` 前，仍必须用目标地域/模型的官方 API 文档或真实 endpoint 契约探测确认单请求输入数量、模态组合、返回 index 语义和 token/媒体限制。在证据缺失时保持 1，不伪造已验证的吞吐结论。

**目标**

- 在 provider capability 已证明时按模型/API 上限分批；否则使用有限并发单请求；两种路径均有指数退避重试
- **document 目的**：可按 batch 合并（四种画像指令在 document 侧相同，已核实安全）
- **query 目的**：按 `retrievalProfile` **分组批处理**，禁止混合画像同一请求
- 响应：`data[i]` 对应 batch 内第 i 条 input
- 日志：batch 数、重试、耗时

**非目标**

- 不改 embedding 模型
- 不做跨文档全局队列（W3.3）

## 3. 设计要点

```ts
DOUBAO_EMBED_BATCH_SIZE=1
DOUBAO_EMBED_CONCURRENCY=4
DOUBAO_EMBED_MAX_RETRIES=3
```

其中 batch size 1 是能力未核实情况下的安全默认，不是性能最优结论；并发 4、重试 3 是代码默认，也仍需由目标环境的限流、延迟和费用预算校准。

### 分组规则（必须）

| purpose | 分组键 | 说明 |
| --- | --- | --- |
| `document` | 可单键（指令一致） | 按顺序切 batch |
| `query` | `retrievalProfile` | 同画像才进同一 HTTP 请求；不同画像分批 |

### 响应映射（必须）

- 解析 `body.data` 为数组，按 `index` 字段或数组下标写回原 input 位置
- 禁止再写死 `data[0]`
- 缺条/错位 → 抛错并触发该 batch 重试

### 3.1 设计约束 / 扩展点

- **约束**：批处理/重试/映射留在 llm-core；kb 只传文本与画像，不感知 vendor HTTP
- **扩展点**：`embedBatchSize` / `embedConcurrency` 经 config；换模型不改分组键语义
- **反模式**：写死 `data[0]`；不同 `retrievalProfile` 混进同一请求

## 4. 实现与待验证项

- 已实现：分组 → batch → 并发池、响应 index 映射、429/5xx 指数退避、Retry-After、AbortSignal、永久 4xx 不重试。
- 已实现：上述三个 env 配置；默认 batch size 为 1。
- 已有单测：batch 调用次数、混合 query 画像隔离、返回顺序、503 恢复、Retry-After、400 不重试、abort 不发请求。
- 待外部证据：目标地域/模型真实 batch capability、限额、百级 chunk 吞吐和 429 行为。

## 5. 验收

- 在目标环境记录百级 chunk 摄入耗时；未做 live benchmark 前不得声称已下降
- 瞬时 503 可恢复
- 混合画像 query 不会共用错误 instructions
