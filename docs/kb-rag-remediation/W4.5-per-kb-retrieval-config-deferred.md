# W4.5 — per-KB 检索配置覆盖（F-17）— 暂缓说明

> 对照 plan-review G-06：原 overview 映射失真。本文件明示 **暂缓**。

## 现状

检索阈值/权重/prefetch 均为进程级 env（`app.config`），无法按知识库（directory）差异化。

## 暂缓理由

1. 先用 W1.4 + W2.2 标定**全局**可用默认值，再谈分 KB 覆盖
2. per-KB 配置需 UI/API/存储，产品面大于检索内核
3. 与 W4.1 metadata 模型可一并设计，避免两套配置表

## 准入后再做（提纲）

- 先定义版本化 schema；若选择 `directory.settings_json`，必须 schema 校验并禁止未知安全相关键
- `threshold / ruleBoost / modelRerank / lexicalCandidateLimit` 只允许白名单字段
- 检索时 `resolveRetrievalConfig(directoryId)` overlay 全局默认，并生成稳定 `configVersion/fingerprint`
- 控制台编辑页
- 审计：谁在何时改了什么、旧值/新值、回滚版本
- W4.2 exposure/feedback 记录 configVersion，否则无法归因 per-KB 配置收益

## 状态

**暂缓（Deferred）** — 建议在 W2.2 稳定且 W4.1 启动时一并评估。
